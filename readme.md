# 📊 Dashboard Analisis E-Commerce

Dashboard ini dibuat menggunakan **Streamlit** untuk menganalisis data e-commerce dari Brasil. Analisis ini mencakup berbagai aspek bisnis yang dapat memberikan wawasan bagi pemangku kepentingan.

## 🔍 Fitur Analisis:
1. **Produk dengan Pendapatan Tertinggi** 💰  
   - Menampilkan produk-produk yang menghasilkan pendapatan paling tinggi.  

2. **Rata-rata Waktu Pengiriman per Negara Bagian** 🚚  
   - Menganalisis waktu rata-rata pengiriman berdasarkan lokasi pelanggan.  

3. **Hubungan antara Harga Produk dan Kemungkinan Terjual** 📈  
   - Mengidentifikasi apakah harga produk memengaruhi kemungkinan penjualannya.  

4. **Pola Pembayaran Pelanggan** 💳  
   - Menampilkan metode pembayaran yang paling sering digunakan pelanggan.  

5. **Tren Review Rating dari Waktu ke Waktu** ⭐  
   - Menganalisis pola perubahan rating produk dari waktu ke waktu.  

6. **Sebaran Lokasi Pelanggan di Brasil** 🗺️  
   - Menampilkan peta sebaran pelanggan berdasarkan geolokasi.  

7. **Distribusi Kategori Produk** 🏷️  
   - Menganalisis jumlah produk dalam setiap kategori untuk melihat distribusinya.  

8. **Analisis Klasterisasi Pelanggan** 🎯  
   - Mengelompokkan pelanggan berdasarkan pola pembelian mereka menggunakan teknik analisis klaster.  

## 🛠 Teknologi yang Digunakan:
- **Python** 🐍  
- **Streamlit** 🎈  
- **Pandas** 🐼  
- **Matplotlib & Seaborn** 📊  
- **Geopandas & Contextily** 🗺️  
- **Pillow** 🖼️  
- **Scikit-Learn** 🤖 *(untuk analisis klasterisasi pelanggan)*
